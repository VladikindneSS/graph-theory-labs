# graph-theory-labs

### Работу выполнил Максимов Владислав.

В работе представлена реализация восстановления дерева по его двоичному коду, экспорт графа в формат DOT, а также собственная реализация визуализации дерева с использованием библиотеки matplotlib.

## Запуск программы

Для запуска программы необходимо открыть консоль в основной директории проекта и выполнить команду:

```bash
python pract3.py
```

## Результаты работы

После выполнения программы в основной директории проекта будут сохранены следующие файлы:

`tree.dot` - представление графа в формате DOT;

`tree.png` - визуализация построенного дерева.
