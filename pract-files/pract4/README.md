# graph-theory-labs

### Работу выполнил Максимов Владислав

В работе представлена реализация венгерского алгоритма для нахождения минимального по весу полного паросочетания.

Программа поддерживает два режима работы:

1. **Режим 1** — нахождение минимального по весу полного паросочетания в двудольном графе.
2. **Режим 2** — нахождение паросочетания в заданном произвольном графе и сохранение результата в формате DOT.

## Запуск программы

Для запуска программы необходимо открыть консоль в основной директории проекта и выполнить команду:

```bash
python pract4.py
```

## Результаты работы

После выполнения программы в основной директории проекта будет сохранён файл:

* `matching.dot` — представление графа в формате DOT.

## Примечание
